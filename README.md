# OpenCode Free Limit Fix

Небольшой патч для **OpenCode Desktop** (Windows), который убирает плашку
«Достигнут бесплатный лимит» из окна чата и отключает автообновление приложения,
чтобы правки не затирались следующей версией.

## Как убрать лимит

Самый простой способ — **сменить IP**. Например, включить режим полёта на
10–15 секунд и снова выключить (подойдёт и перезапуск роутера или включение VPN).
После смены IP лимит сбрасывается, и бесплатной моделью снова можно пользоваться.

## Что делает патч

| Файл в `app.asar` | Что меняется |
| --- | --- |
| `out/renderer/assets/route-IwQmm3WU.js` | условие показа карточки `session-free-limit` заменяется на `active:()=>!1` — карточка «Достигнут бесплатный лимит» больше не рендерится, вместо неё сразу показывается обычное поле ввода |
| `out/main/platform-DZ0ycknI.js` | из проверки обновлений убирается `await x.checkForUpdates()` — приложение больше не ходит в сеть за обновлениями и всегда считает, что версия актуальна |

Патч делается «в размер»: подменяются байты той же длины, SHA-256 в заголовке
`app.asar` пересчитывается, размер архива не меняется.

## Требования

- Windows 10/11
- OpenCode Desktop **2.4.1** (имена чанков и строк привязаны к этой версии)
- Node.js 22+

## Применение

1. Закрой OpenCode (скрипт умеет работать и на запущенном приложении, но после
   правки приложение нужно перезапустить).
2. Проверь состояние патчей:

   ```bash
   node scripts/check.cjs
   ```

3. Примени патчи (сначала можно посмотреть, что изменится):

   ```bash
   node scripts/remove-free-limit.cjs --dry-run
   node scripts/remove-free-limit.cjs
   node scripts/disable-autoupdate.cjs
   ```

4. Запусти OpenCode заново.

Те же действия через npm-скрипты:

```bash
npm run check
npm run free-limit:dry
npm run free-limit
npm run no-autoupdate
```

Путь к архиву по умолчанию:
`%LOCALAPPDATA%\Programs\ai.opencode.desktop\resources\app.asar`.
Если приложение установлено в другое место, передай `--asar <путь>`.

## Бэкап и откат

- `remove-free-limit.cjs` при первом запуске создаёт рядом `app.asar.bak`
  (≈255 МБ). После проверки, что всё работает, его можно удалить.
- Полный откат — переустановка OpenCode.

## Ограничения

- После ручной переустановки приложения патчи слетают — просто запусти скрипты снова.
- Автообновление отключено: новые версии сами не установятся, обновляться нужно вручную.
- Патч привязан к версии 2.4.1. Для другой версии имена чанков и строки будут
  другими — найди их помощником `scripts/scan.mjs` (нужен `npm install`).

## Структура проекта

```
scripts/
  check.cjs              — показывает, применены ли патчи
  remove-free-limit.cjs  — убирает карточку «Достигнут бесплатный лимит»
  disable-autoupdate.cjs — отключает проверку обновлений
  scan.mjs               — ищет компонент плашки в app.asar (для новых версий)
```
